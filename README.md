# ACE OS

**An(na)other Context Engine OS** · part of *an(na)other context*

An operating system for bottom-up learning, co-designed step by step.

> Status: just started. First topic: what is an operating system, from the hardware up.

## The idea

In Anna's words (lightly edited for grammar):

> An interactive brain dump app with way more evolutionary adaptation capabilities, in a similar style to those "discover all the words and associated" games. Kind of like a wiki: anything can be linked, navigated through, explained, used, applied and shaped in the way I need it to be — translating words, vision, abstracts and drawings as input into other contexts such as visual, audio, sensory.

At its most abstract:

```
input  →  context application  →  desired output
```
